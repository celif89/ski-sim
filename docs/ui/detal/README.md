# Etap 7d – szczegóły z bliska (zrzuty)

Zrzuty z gry w przeglądarce (piaskownica, prawdziwy Pilsko z OpenStreetMap, zima 2026/27 z ziarna
gry), ekran 1920 × 1080, przybliżenie 0,125–0,2 m/px (największe możliwe: 0,125 m/px; skala w lewym dolnym rogu).
Grafika w kontenerze bez karty graficznej (SwiftShader) – na Macu wygląda tak samo, tylko płynniej.

Na tym widoku mierzony był czas klatki. |

Jak powtórzyć: piaskownica → panel „Goście” → „Pilsko z OSM”; ratraki: garaż (narzędzie B) i zakup
w panelu „Naśnieżanie i ratraki”; naśnieżanie: pompownia, przyłącze, zbiornik, rurociąg (H) i armatki
(J); muldy: w „Planie nocy” wyłączyć ratrakowanie tras i przewinąć dzień lub dwa z gośćmi.
Przybliżenie do końca (kółko myszy) – detal śniegu pojawia się od 0,5 m/px, w pełni od 0,35 m/px.
